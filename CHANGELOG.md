
# Historial de versiones

## v1.0.0
- Primera versión liberada del Sistema de Inventario.
- Incorporación de la funcionalidad Producto.
- Implementación de la representación y visualización de productos.
- Incorporación de pruebas automatizadas con Vitest.
- Ejecución satisfactoria de 7 pruebas.
- Generación automática del paquete de distribución.
- Publicación exitosa mediante GitHub Actions.

## v1.0.1
- Versión utilizada para comprobar la detección de errores.
- Se introdujo intencionalmente un error en la asignación del precio.
- Se detectaron 3 pruebas fallidas y 4 satisfactorias.
- GitHub Actions detuvo el proceso de liberación.
- La versión no fue publicada en GitHub Releases.

## v1.0.2
- Corrección del error en la asignación del precio.
- Restauración del funcionamiento de la clase Producto.
- Ejecución satisfactoria de las 7 pruebas automatizadas.
- Generación del paquete de distribución corregido.
- Publicación exitosa de la versión mediante GitHub Actions.
